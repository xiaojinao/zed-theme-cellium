# Cellium Theme for Zed

Cellium 品牌主题，配色与 Cellium Agent 的 TUI（`app/tui/theme.py`）同源。

## 主题

- **Cellium Dark** — `#0d1117` 底、`#58a6ff` 主蓝、`#3fb950` 成功绿

## 安装

Zed → `Ctrl+K Ctrl+T` → 选择 **Cellium Dark**。

## 色板

| 变量 | 色值 |
|---|---|
| background | `#0d1117` |
| surface | `#161b22` |
| panel | `#21262d` |
| border | `#30363d` |
| foreground | `#e6edf3` |
| primary / accent | `#58a6ff` |
| success | `#3fb950` |
| warning | `#d29922` |
| error | `#f85149` |
